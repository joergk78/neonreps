# NeonReps

**NeonReps** is an offline-first workout tracking Progressive Web App (PWA) designed for iPhone. It focuses on fast set logging, progressive overload, and a distraction-free gym experience.

## Project status

🚧 **Work in progress.** The application is under development and has not yet been published through GitHub Pages.

## Planned features

- Flexible, user-configurable workout plans (full-body, upper/lower, 3-way splits, or custom routines)
- Quick weight and repetition adjustments and one-tap set logging
- Automatic display of previously used working weights
- Rest timer with the option to finish a break early
- Flexible handling of skipped exercises and shortened workouts
- Local workout history and progress insights
- Persistent offline storage using IndexedDB
- Data export and import for backups
- Installable home-screen PWA with offline support

## Design

A clean, high-contrast interface: black background, neon-green accents, white numbers, and a minimalist dumbbell icon.

## Privacy

The app is designed to keep personal workout entries on the user's device. The public GitHub repository contains project files, not a user's local workout history.
